## Как отдел формирует оценку

- Штаб начинает с публичного уровня команд. Учитывает сыгранные раунды, силу соперника, счёт по раундам, долю урона и убийств внутри пятёрки. Для entry существенны первые контакты, для support — ассисты и участие в результативных раундах. Состав источника ограничивает выводы. Таблица убийств не измеряет качество капитанских коллов или владение конкретным оружием. В отчёте видно, сколько профильных навыков подкреплено наблюдениями.
- Сотрудник сопоставляет результат с игроками **своей зарегистрированной пятёрки**, чьи текущие ролевые навыки ему доступны по правилам карьеры. Больший вес получают сопоставимые роль и выступления. В основании отчёта указано число игроков сравнения. Референсы другого клуба и потолки развития исключены из расчёта.
- Один опубликованный многокартовый рейтинг несёт больше информации об общем уровне, чем одна карта. Он остаётся одним независимым источником для изученности и не раскрывает отдельных навыков. Старые версии опубликованных отчётов сохраняют исходную методику.
- Интервал учитывает объём и давность выборки, компетенции, разброс выступлений, расхождение источников и долю ненаблюдаемых компонентов ролевого OVR. Скаут использует возраст и изменения сопоставимых показателей из одного типа источника для прогноза развития.
- По окончании широкого поиска отдел проверяет, кто из найденных или ранее отобранных кандидатов действительно выступал в последние 28 дней. Отобранный игрок получает персональное сопровождение до 42 дней. Новый публичный протокол позволяет отделу ИИ начать разбор между еженедельными обходами. Без выступлений задание не создаёт дополнительных отчётов.

На всех трёх выборках у квалифицированного специалиста уже интервалы и меньше средняя ошибка прогноза потенциала. Преимущество в абсолютной ошибке середины текущего OVR между квалификациями эти выборки не показали. В двух парных сравнениях с первоначальным PR все три квалификации точнее оценили текущий уровень. У Vexite ранняя середина диапазона оказалась ближе к эталону, чем поздняя. Тренд ошибки конкретного игрока не был условием отбора.

## Воспроизведение

- `python -m tools.measure_focused_scout --player Vexite --seed 5303` — одинаковые 60 дней для трёх квалификаций и продолжение без новых игр.
- `python -m tools.measure_focused_scout --cohort --seed 5303` — по два игрока каждой роли. Для повторов использованы зёрна 7811 и 9049.
- `python -m tools.measure_round_career --days 365 --scouting` — год профессиональной сцены через карьерный календарь и SQLite.
- `python -m tools.measure_scouting --years 5` — пятилетняя сцена с заданным начальным разбросом навыков. Все четыре нагрузочных сценария запускаются вручную.
