# Оригинальные эмблемы для домашней игры

В базе 287 команд и 36 организаций. Windows ZIP и обычный экспорт базы содержат локальные эмблемы для всех 323 записей. Домашний сервер может подключить вторую библиотеку. Оригинал из неё появится в списках, профилях команды и организации, заявках, примерочной и матч-центре. Своя эмблема, сохранённая в редакторе, имеет приоритет.

| Где играет пользователь | Команды с оригиналом | Команды с игровой эмблемой | Организации с оригиналом | Организации с игровой эмблемой |
|---|---:|---:|---:|---:|
| Обычная поставка | 27 | 260 | 17 | 19 |
| С полным личным пакетом от 25 ноября | 194 | 93 | 34 | 2 |

В полном пакете 164 разных файла для 167 команд. У нескольких записей общий клубный знак. Вместе с графикой основной поставки оригиналы видны у 16 из 16 команд тира 1, у 43 из 48 тира 2 и у 135 из 223 тира 3. Тир относится к игровому срезу. [Поимённый реестр](CLUB_BADGE_SOURCES.md) · [93 команды с игровой эмблемой после установки](CLUB_BADGE_SOURCES.md#команды-без-проверенного-оригинала-для-личного-пакета).

## Установка из готового файла

1. Откройте **База сцены → Оригинальные эмблемы для личной игры**.
2. В поле **Готовый личный пакет с диска (.eslogos)** выберите личный файл. У готового ноябрьского пакета счётчик установленных эмблем покажет **167**. Можно сразу открыть профиль Fnatic или FURIA Esports. Интернет для установки из файла и просмотра не требуется.
3. На телефоне и планшете откройте ту же игру на домашнем сервере. Устанавливать файл на каждое устройство отдельно не требуется. Чтобы вернуть вид основной поставки, нажмите **Отключить личный пакет**.

Личные файлы хранятся рядом с сохранением домашнего сервера в отдельной библиотеке `scenario.club-originals.sqlite`. Обновление основного пакета и экспорт пользовательской базы сохраняют это разделение. Сохраняйте личную библиотеку при переносе игры между своими компьютерами. Готовый личный файл предназначен для использования там, где пользователь вправе сделать личную копию опубликованных знаков. Право выкладывать его в открытый доступ из этого не следует.

## Источники и проверка

Для каждой команды в реестре указаны результаты идентификации, решение по обычной поставке и наличие личной копии. Для 10 команд издатели отдельных загрузок указывают личное использование. Кнопка **Установить по условиям издателей** обращается к этим страницам загрузки. У Fnatic VectorSeek предлагает архив, у FURIA Logotyp.us предлагает SVG. Доступность этих загрузок зависит от сети. В среде сборки они вернули HTTP 403, поэтому для проверки готового полного пакета использованы отдельные архивные PNG с закреплённой версией и контрольной суммой. Условия конкретной загрузки не переносятся на другие копии файла. [Fnatic · бренд](https://fnatic.com/brand) · [Fnatic · загрузка](https://vectorseek.com/vector_logo/fnatic-logo-vector/) · [FURIA · загрузка](https://logotyp.us/get/furia/).

Кнопка **Установить полный личный пакет** сначала проверяет явно разрешённые загрузки. Для остальных версий она позволяет получить указанную в реестре личную копию, когда такое использование допускается применимым правом. Открытый исходный код каталога сам по себе не предоставляет прав на знаки организаций. Для каждой архивной копии закреплены адрес, версия, SHA-256 и независимая страница клуба или состава. Логотип может относиться к дате состава. [Машиночитаемый реестр](../backend/data/personal-badge-sources.json).

Сервер принимает из личного архива только известные PNG по контрольной сумме. Он проверяет формат и прозрачность, приводит поля и размер к единому масштабу и сохраняет результат локально. Установка повреждённого архива целиком откатывается. Отказы внешних сайтов и ошибки показываются по клубам. Для 93 команд в реестре указан конкретный результат поиска. Спорный тёзка, иной исторический знак и файл с непрозрачным фоном требуют дополнительного подтверждения перед включением.
