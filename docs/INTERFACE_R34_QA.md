# Визуальная приёмка R3.4

В парных снимках слева открыт интерактивный эталон из приложенного архива, справа — игра на той же ширине.

## Что проверялось

- На широком экране меню остаётся слева. На смартфоне открывается выдвижная навигация, основные игровые кнопки доступны касанием. В профиле открываются все группы характеристик, а широкие таблицы прокручиваются внутри панели.
- Проверены переходы из кабинета в письмо и календарь, из состава и поиска в профиль, из структуры клуба в команду и из базы сцены в профиль сотрудника.
- В матче используется серверная карта Депо. Отдельная панель команды на смартфоне показывает состав и экипировку. Портреты, эмблемы, результаты матчей и открытые оценки взяты из игровой редакции. Для игроков без установленной фотографии виден игровой портрет.
- Редактор тактик использует сохранённые маршруты. В календаре представлены события действующей карьеры. В разделах, связанных с будущими этапами, показаны только доступные игровые сведения.
