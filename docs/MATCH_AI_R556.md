# R5.5.6. Техническая приёмка матчевого ИИ

**Итог.** На `fde3786` после PR #49 все 36 зачётных BO1 завершились штатно. В 772 раундах журнал событий согласуется со счётом, экономикой и проверенной статистикой всех десяти игроков. Существенных ошибок, требующих исправления игрового кода, в этих проверках не обнаружено.

**Выборка.** 44 полных запуска подробного ядра C++: 36 разных стартов и 8 контрольных повторов. На каждой из девяти карт сыграны две пары с seed `55300 + i` и `55600 + i`, где `i` — индекс карты в `cs2_maps.NAMES`. Внутри пары совпадают seed, обе заявки и их порядок. В колонке `start` указан номер заявки, начинающей за T. Счёт в CSV дан в порядке заявок. Набор данных — `scene-202611`, сборка карт 26879581, политика 11, правила `cs2-bo1.20`, физический checkpoint 7. [Результаты 36 стартов, заявки, тайминги и SHA-256](MATCH_AI_R556.csv)

**Воспроизводимость.** Для обеих сторон на Nuke (`55606`) и Anubis (`55301`) полный финальный SHA-256 совпал при обычном ходе пакетами по 512 тиков и после загрузки с тика 180 с пакетами по 127. На Ancient четыре старта повторены в другом процессе с `PYTHONHASHSEED=47` — совпали все четыре хеша. В серии целевых тестов прошли 274 проверки. Одна проверка запуска миграции через локальный сокет потребовала повторного запуска с доступом к loopback.

**Производительность.** Debian 13 x86-64, Xeon Platinum 8573C, лимит 4 CPU и 16 ГиБ, GCC 14.2 Release, Python 3.12.14. На 36 зачётных BO1 пришлось 423,019 с процессорного времени. Медиана среднего времени тика по матчам — 485 мкс, диапазон 409–1 335 мкс. Расчёт включает вызовы ядра и замер RSS на границах пакетов, загрузка геометрии и разбор финального журнала выполнялись за пределами этого интервала. Максимумы RSS процесса по матчам — 136,7–398,8 МиБ при выборке каждые 512 тиков. Короткие пики внутри пакета и рост памяти за сезон здесь не измерялись.

## Как повторить

Из корня проекта в окружении Python 3.12 с зависимостями из `requirements-test.txt` и `requirements-native.txt`. Каждый процесс пишет CSV одной карты. Полная команда ниже даёт 44 BO1, включая четыре независимых повтора Ancient.

```bash
python -m tools.build_native
python -m backend.map_install
mkdir -p build/r556-results
for map in ancient anubis cache dust2 inferno mirage nuke train vertigo; do
  python -m tools.accept_match_ai "de_${map}" "build/r556-results/${map}.csv" || exit 1
done
PYTHONHASHSEED=47 python -m tools.accept_match_ai de_ancient build/r556-results/ancient-repeat.csv
diff <(cut -d, -f24 build/r556-results/ancient.csv) <(cut -d, -f24 build/r556-results/ancient-repeat.csv)
python -m pytest -q tests/test_{individual_decision,peer_radio,small_groups,group_tasks,team_attack,attack_options,team_defense,grenade_effects,native_match_state,match_inventory,checkpoints}.py \
  tests/test_installed_maps.py::test_recent_checkpoints_resume_from_the_recorded_tick
```
