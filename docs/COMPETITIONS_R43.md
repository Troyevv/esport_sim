# Соревнования в карьере R4.3

В главном меню выберите **Новая карьера → редакция базы от 25 ноября 2026 года**. Кабинет открывает разделы **Соревнования** и **Рейтинг VRS**. Откройте клуб с невысоким рейтингом, например SINNERS Esports, чтобы сыграть открытый отбор CCT. Выбор участника уже начавшегося Major или CCT даёт доступ к его действующей заявке и следующему матчу.

Ноябрьская карьера рассчитывает полную сцену во всех регионах. Для архивных редакций сохраняется выбор охвата.

В списке турниров работают фильтры названия, региона, месяца и участия клуба. Карточка показывает даты, источник, условия допуска и распределение денег по местам. Отдельные вкладки открывают заявки, сетки по раундам, результаты и статистику. Матчи в тот же день могут идти один за другим. Кнопка наблюдения у чужой серии останавливает календарь перед началом и открывает тот же матч-центр, что и игра своей команды.

Подтверждённые даты турнира и опубликованные команды относятся к срезу на старт карьеры. Составы CCT используют заявленные командные слоты и доступные на эту дату пятёрки. Для дат без отдельного опубликованного регламента карточка указывает игровой дедлайн. В будущих изданиях с пометкой «Игровой сезон» игра заново определяет состав участников, победителей и даты повторяющихся кубков. Престиж служит оценкой для решений ИИ. Для wildcards Rivals и ESL Pro League S26 учитываются предыдущие пятёрки из топ-12 и финалисты турниров за полгода. При отсутствии подходящих кандидатов место переходит следующему составу по VRS. Стартовый календарь покрывает перечисленные серии.

## Допуск и состав

1. На вкладке **Моя заявка** примите приглашение или зарегистрируйтесь на открытый отбор. Для европейского кубка ECL подтвердите предложенное место до срока ответа.
2. Выберите пять основных игроков, запасных в пределах регламента и тренера. При каждом сохранении заявка получает новую версию. До фиксации можно изменить её или отказаться от участия.
3. После фиксации матч использует версию заявки турнира. Уход игрока из организации меняет его доступность. Для экстренной замены укажите основание и поднимите одного из зарегистрированных запасных. Для Major проверяется регион пятёрки. Игрок академии может числиться запасным первой команды в другом турнире. При активации запасного проверяется занятость в основной пятёрке. В пределах одного турнира игрок может входить лишь в одну заявку. Решения о снятии и проходе без соперника сохраняются в сетке.
4. Победа в отборе создаёт отдельную заявку следующего турнира со ссылкой на квалификацию. При пересечении дат у пользователя остаётся право выбрать соревнование. ИИ учитывает уже зафиксированные обязательства, престиж и призовые. Письма и напоминания появляются в общем кабинете.

Протокол каждой серии хранит версии её составов. Итоговые призовые и клубные выплаты образуют отдельную запись на издание. Архив игровой карьеры показывает распределение мест, MVP по среднему урону за раунд и матчи. У исторических турниров до начала карьеры доступны дата, победитель и сумма из опубликованного набора. Детальная статистика раундов собирается в матчах, сыгранных игровым ядром.

## Рейтинг

В раскрывающемся списке **Снимок** доступны опубликованные таблицы Valve за август — ноябрь 2026 года и последующие ежемесячные публикации карьеры. Переключение на **Расчёт карьеры** показывает таблицу по последним завершённым соревнованиям. Региональный фильтр и поиск работают для каждого снимка. Рейтинг привязан к игрокам и ядру состава. Для приглашения сохраняется снимок на соответствующую дату.

Расчёт использует редакцию официальной модели Valve, закреплённую в исходниках. Стартовый корпус включает 6 731 рейтинговую серию в 180-дневном окне. Разница между опубликованными очками Valve и пересчётом карьеры зависит от покрытия и идентификации игроков в источниках. ## Воспроизведение проверок

Из корня репозитория запускаются модульные сценарии и проверка с установленным пакетом карт.

```bash
python -m pytest -q tests/test_competitions.py
python -m tools.check_competition_lifecycle
python -m tools.check_competition_seasons
```

Проверка seasons подаёт контрольные результаты в календарь до января 2028 года и проверяет отсутствие пересечений команд по дням. Скорость матчевого ядра измеряется отдельно.

Для прямого сравнения с JavaScript-моделью нужны локальный checkout Valve на указанном коммите и исходный ZIP с файлом matchdata.json от 25 ноября. Сравниваются порядок, очки, регион и пять имён всех допущенных составов.

```bash
python -m tools.check_competition_vrs /path/to/counter-strike_regional_standings /path/to/november-artifact.zip
cd frontend
npm run build
npx playwright test competitions.spec.ts
```

В GitHub Actions расширенная приёмка кубка запускается вручную или добавлением метки `r4.3-acceptance` к PR. Она проводит кубок Океании на установленной геометрии, сверяет наблюдаемую серию с фоновым расчётом, перезапускает сохранение между картами и проверяет выплаты после загрузки.
