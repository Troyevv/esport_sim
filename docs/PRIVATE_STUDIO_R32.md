# Студийные портреты для личной игры

Актуальный файл `cs2-studio-cutout.esportraits` содержит 338 готовых портретов для 1 715 записей среза от 25 ноября 2026 года. В игре откройте **База сцены → Студийные портреты → Личный пакет портретов (.esportraits)** и выберите файл. Требуется сборка PR #7 с реестром на 338 игроков. После установки один домашний сервер отдаёт портреты на ПК, планшет и телефон без доступа в интернет. С релиза R5.1 у игроков без установленной фотографии отображается постоянный [синтетический портрет](STAFF_R51.md).

Индекс семи специализированных коллекций дал 623 совпадения по файлам. У одного игрока может быть несколько исходников. Всю базу также охватил пакетный веб-поиск студийных и официальных фотографий по 370 группам составов и игроков. Журнал содержит ссылки поисковой выдачи на группу. Попадание страницы в выдачу не подтверждает наличие пригодной фотографии конкретного человека. Прямые обращения к ряду источников, включая HLTV, BLAST и Liquipedia, возвращали HTTP 403 из среды обработки. Поиск продолжался по доступным именным коллекциям. [Результат для каждого игрока](PRIVATE_STUDIO_COVERAGE.csv) · [Журнал группового веб-поиска](PRIVATE_STUDIO_SEARCH.csv).

Принятые слои происходят из NoScope-Assets (292), CS-Community-Ranking (26), DiwmixTV (10), ElitePlayTracker-React (4), fantasy-polymarket (3), elhash-gg (2) и EsportSimulator (1). Принадлежность проверялась по имени файла, игровому нику и источнику записи базы. Точное совпадение ника в архивной коллекции даёт меньшую уверенность, чем именная публикация самой организации. В реестре есть издатель копии, постоянная ссылка на версию файла, источник метаданных игрока, исходные размеры и обе контрольные суммы. Для личного использования картинки передаются отдельно. В публичных исходниках, сохранениях и Windows ZIP содержатся только метаданные этого пакета. [Реестр источников](../backend/data/personal-portrait-sources.json).

## Отбор

На предварительной проверке 11 игроков исключены из-за выражения лица, 7 из-за наклона или поворота головы, 5 из-за прежнего исключения или неоднозначности ника, 3 из-за разрешения, 2 из-за перекрытия лица и 2 из-за стыка шеи с воротником. Для игрока с несколькими исходниками в отчёте дана последняя причина отказа.

Снимки всех 399 кандидатов проверены в реальных игровых профилях. Для отклонённых игроков дополнительно проверены другие версии именных снимков. Из 20 обработанных альтернатив четыре дали пригодные портреты NiKo, kyxsan, xiELO и zweih. По итогам обеих проверок исключены 29 из-за освещения, 13 из-за ракурса, 10 из-за перекрытых глаз, 2 из-за недостатка деталей, 3 из-за контура или аксессуара и 2 из-за выраженной улыбки. Ещё 2 записи (`device` и `dev1ce`) исключены как визуальный дубликат. После повторной проверки первого личного пакета сняты портреты HObbit и divine. Их прежние слои скрываются в обновлённой игре.

Пакетная обработка читает в том числе PNG с прозрачностью в индексированной палитре. Размер туловища в исходном кадре не определяет пригодность лица. Обработчик измеряет расстояние между глазами и детализацию в области лица до нормализации. Для компактных студийных снимков минимальная расчётная ширина композиции составляет 160 пикселей. Игра ограничивает увеличение каждого такого портрета его индивидуальным размером. После сегментации остаются волосы, голова и шея на прозрачном холсте 480 × 560. Внешность и форма отрисовываются отдельно.

## Проверка предыдущего файла

Размер пакета — 32 413 380 байт. SHA-256 — `30ad9c20ecff37c0a5d10551c0ac729d958f3a2d93817b472e9d131762c0c854`. Для повторной сборки в окружении проекта разместите указанные в реестре версии исходных коллекций по пути `<каталог>/<владелец>/<репозиторий>`. Запустите из корня проекта `python -m tools.build_private_portraits <каталог> cs2-studio-338.esportraits`. Сборщик проверяет каждый исходник и каждый итоговый PNG.

Установка готового файла проверена через интерфейс без внешних сетевых запросов. Для donk проверены три комплекта и трансфер из Team Spirit в Astralis в копии базы. После изменения состава игра выбрала форму Astralis и сохранила тот же SHA-256 слоя внешности. Профиль проверен на ПК и в обеих ориентациях смартфона и планшета.
