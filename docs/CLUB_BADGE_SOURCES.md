# Происхождение клубных эмблем

Проверка проведена 25 ноября 2026 года. В реестре перечислены все команды игрового пакета и все отдельные записи организаций. Ссылки на спортивные страницы служат для идентификации клуба. Основание для использования оригинала приведено в собственной колонке. Для игровой версии указан найденный материал и причина решения. Колонка «Эмблема» ведёт к файлу основной поставки. В колонке «Личная библиотека» приведены отдельные источники домашних копий. [Методика и итоговые числа](SCENE_ART_R32.md).
